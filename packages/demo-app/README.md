# @devtools-mcp/demo-app

React 19 + TanStack Query v5 + TanStack Router v1 fixture on http://localhost:5199. Sets
`window.__TANSTACK_QUERY_CLIENT__` and `window.__TANSTACK_ROUTER__` in dev. Contains state/reducer/ref/memo
hooks, context, `memo()`, Suspense, a paginated query with search params and a mutation — the shapes the e2e
suite asserts on. `pnpm dev` to run it standalone.
